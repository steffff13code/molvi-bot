# CA-бандл для проверки TLS Сбера (GigaChat / SaluteSpeech)

`bot/config.py::sber_verify()` использует `settings.sber_ca_bundle`, если он указывает
на существующий файл, и иначе честно верифицирует по системному хранилищу (certifi).
Здесь должен лежать `russian_trusted_root_ca_pem.crt` — корневой сертификат НУЦ Минцифры,
которым подписаны сертификаты некоторых российских сервисов (в т.ч., возможно, Сбера)
после ухода западных CA.

**Файл сюда не положен намеренно** — эта сессия не смогла скачать его
(`https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt` недоступен из
песочницы), а подделывать содержимое сертификата небезопасно. Владельцу нужно:

1. Скачать `russian_trusted_root_ca_pem.crt` по ссылке выше (официальный источник —
   Минцифры, `gosuslugi.ru`/`reestr-pki.gov.ru`) и положить в этот каталог.
2. Указать путь в `.env`: `SBER_CA_BUNDLE=assets/certs/russian_trusted_root_ca_pem.crt`.
3. Проверить, что бот всё ещё может вызывать GigaChat/oauth (сейчас `sber_verify_ssl=True`
   по умолчанию — если сертификат Сбера в итоге подписан именно этим корнем, а бандл не
   указан, TLS-верификация будет падать системным certifi; см. примечание в PR-7).
